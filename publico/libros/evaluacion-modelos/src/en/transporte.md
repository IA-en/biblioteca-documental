# Transport, preservation and measurements

Comparability concerns document content, the examination contract and recorded conditions. Services may need different technical envelopes. Each adaptation must preserve complete content, exclude the answer key and retain instruction meaning. A model name alone does not establish identical configuration or context.

Preparation records the edition, presented order, document and package hashes, adapter identity and exact recipient configuration when selected. Context capacity must be checked for that configuration; it cannot be inferred from byte size or a commercial name alone.

The absolute limit is 300 seconds for complete delivery and reception. A connection cut after sending can leave remote processing uncertain. No automatic retry is permitted. A further attempt requires its own identity and grounds, preserving the first attempt and leaving unknown costs unknown.

| Observation | Appropriate record |
| --- | --- |
| The original does not fit, or resources are missing. | Preparation stopped; no delivery or verdict. |
| The adaptation changes the package. | Instrument defect; no candidate grade. |
| Complete reception is not established. | Transport incident and effects awaiting reconciliation. |
| A complete response has an invalid format. | The edition's prior formal consequence. |
| A complete valid response contains content errors. | Grading by key and criticality. |

An HTTP error or interruption alone does not establish responsibility of GitHub, hosting or the model provider. Preserve observations and references before attributing a cause.

Telemetry records SV-observed duration, provider-reported input and output tokens, auxiliary usage and cost, with units, source and availability. Missing counters remain absent. Aggregate shared-account consumption is not automatically charged to an examination.

Provider-supplied auxiliary text is preserved separately from the final answer, with its limits. The candidate is not asked to reveal hidden reasoning or report its own measurements. Missing administrative measurements do not silently alter the grade of a complete response.
