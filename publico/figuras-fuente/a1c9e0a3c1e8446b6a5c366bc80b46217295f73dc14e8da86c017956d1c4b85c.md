# Lectura de la figura

Fuente estructurada común; sin OCR. El orden documental no acredita relaciones espaciales.

1. Ruta crítica entre cinco elementos de conocimiento
2. Ejemplo conceptual\. La regla declarada exige A antes de B, B antes de C, C antes de D y D antes de E, sin omitir ninguno\. La ruta A B C D E es la única que satisface estas condiciones\. A B D E omite C; A C B D E incumple una dependencia\. El recorrido registrado se representa aparte: A y B acreditados, C pendiente, D y E no admitidos todavía\.
3. Ruta crítica: conocimiento necesario y dependencias
4. Ejemplo conceptual; no constituye una ruta profesional ni un algoritmo de decisión\.
5. Regla del ejemplo
6. Se requieren A, B, C, D y E; cada elemento depende del anterior\. No se admite omitirlos\.

13. Flecha: dependencia exigida\. Cada elemento identifica conocimiento completo o una parte delimitada\.
14. 2\. Variaciones que no satisfacen la regla
15. A → B → D → E
16. Falta C: omisión de conocimiento necesario\.
17. A → C → B → D → E
18. Incluye todos; C se recorre antes de su requisito B\.
19. 3\. Recorrido efectivamente registrado: ejemplo parcial
20. A, B: acreditados · C: pendiente · D, E: todavía no admitidos
21. La ruta dibujada no acredita su cumplimiento\. Cada paso necesita su evidencia\.
22. Al seleccionar C: Universo y parámetros → documento y versión → páginas o pasajes → evidencia\.
23. La unicidad procede de las reglas de este ejemplo\. La criticidad real exige una definición autorizada\.
