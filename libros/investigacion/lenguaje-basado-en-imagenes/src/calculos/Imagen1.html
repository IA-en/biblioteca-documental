Cálculo desarrollado: Imagen1

Se desarrolla el cálculo de Imagen1 a partir de sus muestras digitales. Todas las imágenes del conjunto son sintéticas. La escena representada no interviene como una etiqueta verbal en el cálculo.

1. Contar las muestras y fijar su orden

Anchura: 1254; altura: 1254. Píxeles: 1254 × 1254 = 1572516. Cada píxel aporta cuatro componentes de ocho bits: rojo, verde, azul y opacidad. Se leen las filas de arriba abajo y cada fila de izquierda a derecha.

Componentes: 1572516 × 4 = 6290064. Se añaden 16 octetos de perfil y dimensiones: 6290064 + 16 = 6290080. Por tanto, m = 6290080 × 8 = 50320640; N = m + 2 = 50320642.

2. Obtener el entero C de las muestras

Los dos primeros píxeles aportan estas ocho componentes decimales, leídas del original:

207, 174, 140, 255, 211, 174, 138, 255

La terminación de perfil y dimensiones es:

83, 86, 73, 77, 71, 48, 50, 0, 0, 0, 4, 230, 0, 0, 4, 230

Si x₁,…,xL son los 6290080 octetos, C = Σ xⱼ·256L−j. Equivalentemente, C₀=0 y Cⱼ=256·Cⱼ₋₁+xⱼ, hasta j=6290080. El comienzo se calcula así:

C₁ = 256 × 0 + 207 = 207
C₂ = 256 × 207 + 174 = 53166
C₃ = 256 × 53166 + 140 = 13610636
C₄ = 256 × 13610636 + 255 = 3484323071
Primeros ocho octetos: A = 14965053642194717439

Se continúa la misma recurrencia con todas las componentes y los 16 octetos finales. Los primeros píxeles permiten comprobar la cifra abreviada; el valor exacto conserva también los restantes.

3. Aplicar las fórmulas de los polos

μ = 3·250320640 + C
λ = 250320640 − 1 − C
P = μ − λ = 250320641 + 2C + 1
I = μ + λ = 250320642 − 1.

Estas expresiones son exactas. El fichero entero completo en texto, base 16 contiene todos los dígitos de P y se abre como texto ordinario. La base 16 expresa el mismo número que la base decimal; no es una huella ni una cifra sustitutiva.

4. Normalizar y controlar la aproximación

q = P/250320642. Para comprobar su aproximación sin escribir millones de dígitos, se usan los ocho primeros octetos:

q₀ = 1/2 + A/2^65
   = 33411797715904269055/36893488147419103232
   = 0.90562859175574058481837484702037244232997181825339794158935546875

La división anterior es exacta para q₀. La contribución omitida satisface 0 < q−q₀ < 2−65, aproximadamente 2,71·10−20. Esta cota sólo se usa para la lectura abreviada; P y q se conservan completos.

5. Sustituir en la recta Atlas

El convenio visual fija η=1/10 y escala 64. Con q ≈ 0.90562859175574062:

1 + 10q ≈ 10.05628591755740686
ln(1 + 10q) ≈ 2.30819790341730213
ln(11) ≈ 2.39789527279837067
δ = 64 × ln(1 + 10q) / ln(11)
  ≈ 61.605970658723

La derivada de esta transformación es menor que 45 en el intervalo utilizado. Por tanto, la diferencia debida a sustituir q por q₀ es menor que 45·2−65, aproximadamente 1,22·10−18. Los decimales impresos incorporan además el redondeo de su evaluación numérica; no se emplean para recuperar la imagen.

6. Calcular los polos Atlas y comprobar el resultado

μAtlas = 64 + δ/2 ≈ 94.802985329362
λAtlas = 64 − δ/2 ≈ 33.197014670638
PAtlas = μAtlas − λAtlas = δ ≈ 61.605970658723
IAtlas = μAtlas + λAtlas = 128

Las sumas y diferencias se refieren a las expresiones sin redondear. Para el retorno exacto, N se obtiene de la longitud binaria de P; m=N−2 y C=(P−2m+1−1)/2. Se restituyen los m bits, las dimensiones y las muestras. En este recurso se ha contrastado la igualdad de todas las muestras con el original.
